# Gimbol — O lugar onde a história continua

Demonstração pública com Gibi e Narrada completos no mesmo bundle. Abre em Narrada; o seletor permite trocar para Gibi na mesma cena. O convite para Ricardo é dividido entre Miguel e Lívia, sem balões, com 6 segundos após a locução para leitura.

https://hugo-dutra.github.io/gimbol-convite-demo/

Somente runtime e mídia públicos; nenhuma fonte privada, sessão ou API. A primeira cena começa após Iniciar história, que também solicita tela cheia.
